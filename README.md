# ![Desafio](https://img.shields.io/badge/Desafio-Super%20Trunfo%20Países-6A0DAD?style=for-the-badge&logo=github&logoColor=white)

Este repositório reúne o trabalho desenvolvido para o **curso de Engenharia de Software**.  

---

## ![Novato](https://img.shields.io/badge/Nível-Novato-6A0DAD?style=for-the-badge)

No nível **Novato**, foi implementada a lógica básica de comparação entre cartas utilizando `if` e `if-else`.

### 🚩 Objetivos
- **Cadastro de Cartas:** Inserção de informações como estado, código da carta, cidade, população, área, PIB e pontos turísticos.  
- **Comparação de Cartas:** Comparação de atributos de duas cartas e determinação da vencedora com base em uma propriedade específica.  
- **Exibição de Resultados:** Mostrar qual carta venceu (maior valor vence, exceto densidade populacional, onde o menor vence).  

---

## ![Aventureiro](https://img.shields.io/badge/Nível-Aventureiro-000000?style=for-the-badge)

No nível **Aventureiro**, o sistema foi expandido para incluir comparação aninhada e menu interativo com `switch`.

### 🚩 Novas Funcionalidades
- **Menu Interativo:** O jogador escolhe atributos para comparação.  
- **Comparação Aninhada:** Lógica mais complexa, considerando múltiplos atributos.  
- **Exibição de Resultados:** Indicação da carta vencedora e do atributo utilizado.  

---

## ![Mestre](https://img.shields.io/badge/Nível-Mestre-6A0DAD?style=for-the-badge)

No nível **Mestre**, foram adicionadas funcionalidades avançadas.

### 🚩 Novas Funcionalidades
- **Comparação de Dois Atributos:** Escolha simultânea de dois atributos para determinar a vencedora.  
- **Lógica Avançada:** Uso de operadores ternários e estruturas aninhadas.  
- **Menus Dinâmicos:** Navegação fluida entre opções de comparação.  
- **Empates:** Tratamento adequado e mensagens específicas.  
- **Exibição de Resultados:** Resultados claros e interativos.  

---

## ![Requisitos](https://img.shields.io/badge/Requisitos-Funcionais%20e%20Não%20Funcionais-000000?style=for-the-badge)
